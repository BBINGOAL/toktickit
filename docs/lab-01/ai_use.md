## Overall Reflection
จากการทำ Lab ครั้งนี้ผมได้ใช้ AI Agent (Gemini) ซึ่งประกอบประกอบไปด้วย โมเดล Claude Sonnet 4.6 เเละ Gemini Pro 3.1 ในการทำLabครั้งนี้ สาเหตุมาจากผมมีประสบการณ์ในการทำ website ไม่มากนักจึงต้องอาศัย AI Agent ในการช่วยสร้างโครงสร้างของไฟล์ เเละหาerrorต่างๆที่เกิดขึ้นเเละทำการเเก้ไข เเละเรียนรู้หลักการทำงานของโปรเจกต์ เพื่อให้ผมให้เข้าใจกระบวนการ   เเละจุดประสงค์ต่างๆของการทำงานของprojectได้อย่างถูกต้อง การใช้ AI ร่วมในการทำ Labครั้งนี้ไม่ใช่เเค่ลดระยะเวลาของการทำงานลงเเต่ยังช่วยให้ผมได้เรียนรู้หลักการทำงานของAI Agent เเละสามารถนำไปประยุกต์ใช้กับการทำงานอื่นๆของผมได้อีกด้วย เเต่การใช้ AI ก็มีข้อเสียเช่นกันซึ่งAI ในปัจจุบันหากเราให้ทำงานให้เลยก็จะเกิดผลเสียตามมาได้อย่างเเน่นอนฉะนั้นเเล้วการใช้Ai เราต้องคำนึงถึงภาพรวมเเละFlowของการทำงานด้วยเพราะหากเกิดข้อผิดพลาด ก็จะสามารถเเก้ไขได้

**สิ่งที่ AI ทำได้ดี**
1. เมื่อระบบมีปัญหา เช่น ปัญหา Volume ของ Docker หรือการเชื่อมต่อ Database ไม่สำเร็จ AI สามารถวิเคราะห์จากข้อความ Error และอธิบายสาเหตุรวมถึงวิธีแก้ปัญหาได้อย่างตรงจุด
2. ช่วยอธิบายเเนวคิดเเละหลักการที่ซับซอน AI ไมได้แค่ให้โค้ดสำเร็จรูปมาอย่างเดียว แต่ยังสามารถอธิบายการทำงานของแต่ละส่วนได้อย่างละเอียด เช่น อธิบายการทำงานของไฟล์ `docker-compose.yml` หรือการเขียนไฟล์ Test ทำให้เข้าใจกระบวนการทำงานได้ลึกซึ้งยิ่งขึ้น
3. ลดเวลาในการตั้งค่าพื้นฐาน การตั้งค่า Environment ต่างๆ มักจะมีรายละเอียดเยอะและใช้เวลามาก แต่ AI ช่วยสรุปเป็นคำสั่งและขั้นตอนสั้นๆ ทำให้ประหยัดเวลาและสามารถนำไปมุ่งเน้นที่การทำความเข้าใจ Logic หลักของโปรเจกต์ได้เร็วขึ้น

**สรุปภาพรวม**
การมี AI Agent เข้ามาช่วยเปรียบเสมือนการมี Pair Programmer ที่คอยให้คำปรึกษาตลอดเวลา ทำให้การทำงานใน Lab 1 ราบรื่นและมีประสิทธิภาพมากขึ้นอย่างเห็นได้ชัด AI ช่วยลดอุปสรรคทางเทคนิคสำหรับคนที่มีประสบการณ์น้อย และทำให้เราสามารถทำโปรเจกต์ Full-Stack ให้เสร็จสมบูรณ์ได้ พร้อมกับได้รับความรู้ความเข้าใจที่เพิ่มขึ้นด้วย
