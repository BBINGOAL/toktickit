## Overall Reflection
จากการทำ Lab 2 ครั้งนี้ ผมได้ใช้ AI เข้ามาช่วยในหลายๆ ด้าน โดยเฉพาะในเรื่องของ **End-to-End (E2E) Testing** ด้วย Playwright และการทำ **Responsive UI** ซึ่งเป็นเรื่องใหม่ที่ท้าทายมาก AI ช่วยเเก้ไขช่องโหว่และช่วยหา Bug ทั้งในฝั่ง Frontend และ Backend ที่เชื่อมโยงกัน (เช่น การที่ Dropdown ว่างเปล่าเพราะค่า API หายไป)

การทำงานกับ AI ในเฟสนี้ทำให้เห็นว่า AI ไม่เพียงแต่ช่วยเขียนโค้ด แต่ยังเป็นผู้ช่วยในการ **Debug ข้ามระบบ (Cross-stack Debugging)** ได้ดีมาก อย่างไรก็ตาม ผมยังคงต้องตรวจสอบ Log ของฝั่ง Server ควบคู่กับภาพ Screenshot จาก Playwright ด้วยตัวเอง เพื่อคอยให้ Context ที่ถูกต้องกับ AI ทำให้เกิดกระบวนการเรียนรู้และเข้าใจการทำงานจริงของโปรเจกต์มากขึ้น

**สิ่งที่ AI ทำได้ดี**
1. การเขียน E2E Test: AI เข้าใจ Flow การทำงานของเว็บเป็นอย่างดี และสามารถเขียนโค้ดจำลองผู้ใช้งานจริงได้อย่างครบถ้วน
2. การหาจุดบกพร่องข้ามไฟล์: AI สามารถวิเคราะห์ได้ว่าปัญหาที่หน้า UI (Dropdown ว่าง) มีสาเหตุมาจากข้อมูลที่ไม่ครบถ้วนของฝั่ง Backend
3. การจัดการกับข้อผิดพลาดทางเทคนิค: เช่น ปัญหา Timeout ของ Playwright หรือปัญหาการหา Locator ซ้ำซ้อนใน DOM

**สรุปภาพรวม**
AI ช่วยเพิ่มความมั่นใจในการพัฒนาฟีเจอร์ใหม่ๆ และทำให้ผมสามารถเขียน Testing ให้มีความครอบคลุมมากขึ้น การได้ทำ Lab 2 นี้ได้เเสดงให้เห็นชัดเจนว่า AI เป็นเครื่องมือสำคัญในการทำงานแต่ผู้ใช้ยังคงต้องมีพื้นฐานความเข้าใจเพื่อนำทางและตรวจสอบความถูกต้องด้วยตนเองเพื่อไม่ให้เกิดข้อผิดพลาดในงาเกิดขึ้น
