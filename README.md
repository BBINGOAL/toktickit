# TokTickIT

## Prerequisites
- Node.js v18+
- PostgreSQL

## Setup

### Backend
\```bash
cd server
npm install
cp .env.example .env
# แก้ไข .env ด้วย DB credentials ของคุณ
npm run dev
\```

### Frontend
\```bash
cd client
npm install
npm run dev
\```

## Running Tests
\```bash
# Backend tests
cd server && npm test

# Frontend tests
cd client && npm test
\```
